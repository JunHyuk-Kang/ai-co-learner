# 사고력 봇 사용 가이드

> 이 봇은 답을 주는 봇이 아닙니다.
> **생각을 한 발 떨어져서 바라보게 만드는 파트너**입니다.

---

## 이 봇은 어떻게 다를까?

"맞아요", "틀렸어요"라고 하지 않습니다.
더 좋은 생각을 알려주지도 않습니다.

대신 이런 질문을 합니다:
- "왜 그렇게 생각해?"
- "그게 이유가 되려면 뭐가 더 필요할까?"
- "반대로 이게 안 맞는 경우도 있을까?"

이 질문들을 따라가다 보면, **처음엔 몰랐던 자기 생각의 구조**가 보이기 시작합니다.

---

## 시작하는 방법

봇이 먼저 이렇게 물어볼 거예요:

> "오늘 어떤 주제나 생각이 있어? 최근에 맞다/틀리다 판단한 것, 선생님이 준 주제, 뭐든 좋아."

뭘 말해도 됩니다. 완성된 생각이 아니어도 됩니다.

```
"스마트폰을 교실에서 쓰면 안 된다고 생각해요."
"숙제가 너무 많은 것 같아요."
"AI가 발전하면 일자리가 없어질 것 같아요."
```

한 줄짜리 의견으로 충분합니다.

---

## 봇이 어떻게 따라오는지

봇은 내 생각의 깊이를 파악해서 질문 방향을 잡습니다.

### 생각이 아직 막연할 때
"그냥요", "다들 그러잖아요"처럼 이유가 잘 없을 때:

```
학생: "일회용품을 금지해야 해요."
봇: "왜 그렇게 생각해?"
```

이유를 찾는 것부터 시작합니다.

### 이유는 있는데 막히는 지점이 있을 때
이유를 말했는데 "그게 왜 맞아?"를 물으면 답이 잘 안 나올 때:

```
학생: "쓰레기가 많아지니까요."
봇: "쓰레기가 많아진다는 게 금지해야 하는 이유가 되려면, 뭐가 더 필요할까?"
```

이유의 이유를 찾아 들어갑니다.

### 설명은 잘 되는데 한 방향만 볼 때
논리는 있는데 반대 경우나 예외를 생각 안 했을 때:

```
학생: "환경 오염이 돌이키기 어려운 피해를 주니까요."
봇: "그 이유가 맞다면, 반대로 금지하면 안 되는 상황도 있을까?"
```

한 방향에서 옆으로 넓혀줍니다.

---

## 막혔을 때

"모르겠어요"라고 해도 됩니다.

봇은 버리지 않고 선택지를 줍니다:

```
봇: "막혔구나. 이런 주제를 생각할 때 많이 쓰는 기준들이야:
     - 환경에 미치는 영향
     - 사람들의 불편함
     - 실제로 지킬 수 있는지
     이 중에 지금 생각이랑 가까운 게 있어?"
```

선택지에서 고르기만 해도 됩니다. 거기서 다시 이어갑니다.

---

## 이 봇에게 기대하면 안 되는 것

- **"정답이 뭐예요?"** → 정답을 알려주지 않습니다
- **"제 생각이 맞아요?"** → 맞다/틀리다 판정을 하지 않습니다
- **"더 좋은 생각 알려주세요"** → 더 좋은 방향을 제시하지 않습니다
- **사실 확인** → "플라스틱이 분해되는 데 몇 년이에요?" 같은 사실 정보는 다루지 않습니다

---

## 잘 활용하는 팁

**처음에 의견을 하나 딱 말하기**: "저는 ~라고 생각해요." 한 문장으로 시작하면 봇이 바로 따라올 수 있어요.

**봇의 질문에 틀린 답은 없음**: 봇은 평가하지 않으니 생각나는 대로 말해도 됩니다. "잘 모르겠는데..."도 괜찮습니다.

**한 주제를 끝까지**: 중간에 다른 주제로 바꾸면 깊이가 생기지 않아요. 하나를 파고드는 게 효과적입니다.

---

## 한 세션을 잘 마무리하려면

1. **처음 생각 vs 지금 생각 비교** — 달라진 부분이 있는지
2. **가장 막혔던 질문** — 거기가 내 생각의 취약한 지점
3. **"이게 안 맞는 경우"** — 봇이 물었던 반례, 스스로 하나 더 찾아보기
