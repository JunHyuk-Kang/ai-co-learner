# 창의력 봇 사용 가이드

> 이 봇은 좋은 아이디어를 골라주는 봇이 아닙니다.
> **아이디어가 다른 모습으로 변할 수 있음을 경험하게 해주는 파트너**입니다.

---

## 이 봇은 어떻게 다를까?

"더 좋은 아이디어가 있어요"라고 하지 않습니다.
"이 아이디어는 별로예요"라고도 하지 않습니다.

대신 이렇게 합니다:
- 내가 말한 아이디어에서 **요소 하나를 바꿔봅니다**
- 조건을 흔들어봅니다
- 관점을 완전히 뒤집어봅니다

"창의적으로 생각해야지"가 아니라 **"아, 이렇게도 달라질 수 있구나"** 를 경험하는 구조입니다.

---

## 시작하는 방법

봇이 먼저 이렇게 물어볼 거예요:

> "오늘 탐구할 주제나 상황이 있어? 아이디어가 있으면 말해봐. 아직 없어도 괜찮아."

**아이디어가 있으면**: 바로 말하면 됩니다. 완성된 아이디어가 아니어도 됩니다.

**아이디어가 없으면**: 괜찮습니다. 봇이 작은 것에서 시작하게 도와줄 거예요.

---

## 아이디어가 없을 때

봇이 이렇게 물어볼 거예요:

> "이 주제나 상황에서 불편하거나 이상하다고 느낀 게 하나라도 있어?"

완성된 생각이 아니어도 됩니다.

```
"매일 비슷한 메뉴가 나오는 게 싫어요."
"급식실이 너무 시끄러워요."
"줄이 너무 길어요."
```

이런 작은 관찰 하나면 충분합니다. 봇이 거기서 아이디어를 끌어냅니다.

---

## 아이디어가 나오면 이렇게 이어져요

봇은 내 아이디어에서 **요소 하나씩** 바꿔보는 질문을 합니다.

```
학생: "남기면 벌칙을 주면 될 것 같아요."
봇: "'벌칙'이라는 요소만 바꾼다면, 전체 구조가 어떻게 달라질까?"

학생: "벌칙 대신 보상이요."
봇: "이 보상이 사람이 아니라 공간에 작동한다면, 어떤 변화가 생길까?"

학생: "급식실 분위기가 달라지는 거요?"
봇: "이 아이디어를 더 펼쳐볼까? 아니면 완전히 다른 방향으로 넘어가볼까?"
```

매번 **계속 확장할지, 다른 방향으로 갈지** 내가 선택합니다.

---

## 같은 아이디어가 반복될 때

비슷한 패턴이 계속 나오면 봇이 완전히 다른 방향을 제안합니다.

```
학생: "또 보상이요." (세 번째 반복)
봇: "이번엔 완전히 뒤집어보자.
     남기는 걸 줄이는 게 아니라, 남기는 걸 허용하는 방향으로 간다면?"
```

낯설게 느껴질 수 있어요. 그게 목적입니다.

---

## 이 봇에게 기대하면 안 되는 것

- **"이 아이디어 좋아요?"** → 평가하지 않습니다
- **"더 좋은 아이디어 알려주세요"** → 봇이 먼저 제안하지 않습니다
- **"왜 이 아이디어가 좋아요?"** → Why 질문을 하지 않습니다
- **아이디어 정리/요약** → 학생이 요청할 때만 합니다

---

## 잘 활용하는 팁

**처음엔 엉뚱한 아이디어도 괜찮아요**: 봇은 판단하지 않으니 떠오르는 대로 말하면 됩니다. 완성도는 상관없습니다.

**"더 펼쳐볼까/다른 방향으로 갈까" 선택이 중요해요**: 이 선택을 의식적으로 하면서 하나를 깊이 파거나 다양하게 넓히는 연습이 됩니다.

**지쳤으면 멈춰도 돼요**: 봇이 "여기서 멈출까?"라고 물어볼 거예요. 충분하다고 느끼면 멈추면 됩니다.

---

## 한 세션을 잘 마무리하려면

1. **처음 아이디어 vs 마지막 아이디어 비교** — 얼마나 달라졌는지
2. **가장 낯설었던 방향** — 거기서 의외로 괜찮은 아이디어가 나오는 경우가 많습니다
3. **실제로 써볼 아이디어 하나 고르기** — 마음에 걸리는 것 하나를 메모해두기
