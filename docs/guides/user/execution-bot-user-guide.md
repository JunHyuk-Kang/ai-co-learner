# 실행력 봇 사용 가이드

> 이 봇은 계획을 짜주는 봇이 아닙니다.
> **"하고 싶다"는 말을 "내가 고른 행동"으로 바꿔주는 파트너**입니다.

---

## 이 봇은 어떻게 다를까?

"이렇게 해봐요"라고 알려주지 않습니다.
"더 현실적으로 해봐요"라고도 하지 않습니다.

대신 이런 질문을 합니다:
- "실제로 뭘 하기로 한 거야?"
- "언제부터 하기로 한 거야?"
- "했다고 말할 수 있는 기준이 뭐야?"

이 질문들을 따라가다 보면 **막연했던 의지가 구체적인 실행 문장**이 됩니다.

---

## 시작하는 방법

봇이 먼저 이렇게 물어볼 거예요:

> "요즘 하고 싶은 게 있어? 또는 해야겠다고 생각하는 것?"

완성된 계획이 아니어도 됩니다.

```
"영어 공부를 해야 할 것 같아요."
"운동을 좀 해볼까 해요."
"수학 문제집을 더 풀어야 해요."
```

이런 막연한 의지로 시작해도 됩니다.

---

## 대화가 이렇게 이어져요

봇은 아직 정해지지 않은 것을 하나씩 물어봅니다.
이미 말한 것은 다시 묻지 않습니다.

```
학생: "영어 공부를 해야 할 것 같아요."
봇: "영어 공부에서 실제로 뭘 하기로 한 거야?"

학생: "단어 외우는 거요."
봇: "언제부터, 얼마나 자주 하기로 한 거야?"

학생: "매일 하려고요."
봇: "매일이면 — 오늘부터? 아니면 특정 날짜부터?"

학생: "이번 주 월요일부터요."
봇: "했다고 말할 수 있는 기준이 뭐야? 단어 몇 개면 '오늘 했다'가 돼?"

학생: "10개요."
봇: "지금까지 나온 걸로 실행 문장을 네 말로 한번 만들어볼래?"

학생: "나는 이번 주 월요일부터 매일 영어 단어 10개를 외운다."
봇: "됐어. 이제 실행하면 돼."
```

마지막 실행 문장은 **봇이 써주는 게 아니라 내가 직접 씁니다.**

---

## 계획이 너무 크다 싶을 때

봇이 줄이라고 말하지 않습니다. 대신 이렇게 묻습니다:

```
학생: "이번 주에 수학 문제집 100문제 풀 거예요."
봇: "이걸 다 못 하게 된다면, 어디까지는 할 수 있을까?"

학생: "30문제요."
봇: "30문제를 언제까지 풀 건지 정해볼래?"
```

스스로 현실적인 크기를 찾게 됩니다.

---

## 이런 말은 봇이 잡아냅니다

아래 표현들은 **아직 선택이 아닙니다**. 봇이 바로 짚어줄 거예요.

| 표현 | 이유 |
|------|------|
| "가능하면 할게요" | 못 해도 되는 조건이 붙어 있음 |
| "상황 봐서요" | 언제 할지 정해지지 않음 |
| "열심히 할 거예요" | 뭘 얼마나 할지 불분명 |
| "습관처럼 하려고요" | 확인 기준이 없음 |
| "일단 해볼게요" | 범위가 열려 있음 |

```
학생: "상황 봐서 운동 좀 해볼게요."
봇: "그 표현이 있으면 선택이 아직 열려 있어.
     이걸 닫으려면 어떤 기준이 있어야 할까?"
```

---

## 이 봇에게 기대하면 안 되는 것

- **"어떻게 하면 좋을까요?"** → 방법을 알려주지 않습니다
- **"제 계획 어때요?"** → 평가하지 않습니다
- **실행 결과 피드백** → 실행 후 어땠는지는 다루지 않습니다
- **동기부여** → "할 수 있어요!" 같은 말을 하지 않습니다

---

## 잘 활용하는 팁

**처음엔 막연하게 시작해도 돼요**: "해야 할 것 같아요" 수준으로 시작하면 봇이 하나씩 좁혀줍니다.

**"했다고 말할 수 있는 기준"이 핵심이에요**: 이게 없으면 실행했는지 아닌지 알 수 없어요. 이 질문에 가장 신경 써서 답해보세요.

**마지막 실행 문장을 직접 써보기**: 봇이 써주는 게 아니라 내 말로 만들어야 진짜 내 선택이 됩니다.

---

## 한 세션을 잘 마무리하려면

1. **실행 문장을 어딘가에 적어두기** — 눈에 보이는 곳에 두면 실행 가능성이 높아집니다
2. **"했다"의 기준 확인** — 오늘 실행하고 나서 그 기준에 맞는지 체크해보기
3. **못 했을 때 대비** — 이번 세션에서 크기를 줄인 적이 있다면, 다음엔 더 작게 시작해도 됩니다
